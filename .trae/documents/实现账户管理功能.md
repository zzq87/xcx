# 账户管理功能实现方案

## 1. 功能需求分析
- 账户分为存款和负债两大类
- 支持多种账户类型：现金、银行卡、支付宝、微信、信用卡、花呗、银行贷款、借给他人、借用他人等
- 支持账户之间相互转账
- 转账后自动更新账户余额

## 2. 实现步骤

### 2.1 页面和配置更新
- 创建新页面：`pages/accounts/accounts`
- 更新 `app.json`，添加新页面并将其添加到 tabBar

### 2.2 数据结构设计
```javascript
// 账户数据结构
const accounts = {
  deposit: [ // 存款账户
    { id: 1, name: '现金', balance: 0, icon: '💵' },
    { id: 2, name: '银行卡', balance: 0, icon: '💳' },
    { id: 3, name: '支付宝', balance: 0, icon: '🐜' },
    { id: 4, name: '微信', balance: 0, icon: '💬' }
  ],
  liability: [ // 负债账户
    { id: 5, name: '信用卡', balance: 0, icon: '💳' },
    { id: 6, name: '花呗', balance: 0, icon: '🌸' },
    { id: 7, name: '银行贷款', balance: 0, icon: '🏦' },
    { id: 8, name: '借给他人', balance: 0, icon: '👤' },
    { id: 9, name: '借用他人', balance: 0, icon: '🤝' }
  ]
};

// 转账记录结构
const transferRecords = [
  {
    id: Date.now(),
    date: '2025-12-30',
    fromAccountId: 5, // 信用卡
    toAccountId: 2,   // 银行卡
    amount: 500,
    note: '信用卡转账到银行卡'
  }
];
```

### 2.3 核心功能实现
- **账户管理**：添加、编辑、删除账户
- **余额显示**：实时显示各账户余额
- **转账功能**：
  - 选择转出账户和转入账户
  - 输入转账金额
  - 自动计算并更新账户余额
  - 保存转账记录

### 2.4 页面设计
- 账户列表：按存款/负债分类显示
- 账户详情：显示余额和交易记录
- 转账界面：选择账户和输入金额
- 操作按钮：添加账户、转账

### 2.5 数据存储
- 使用 `wx.setStorageSync('accounts', accounts)` 存储账户数据
- 使用 `wx.setStorageSync('transferRecords', transferRecords)` 存储转账记录

## 3. 技术要点
- 账户余额计算：存款账户余额为正，负债账户余额为负
- 转账逻辑：转出账户余额减少，转入账户余额增加
- 数据一致性：确保转账操作的原子性
- UI/UX：清晰的账户分类和直观的转账流程

## 4. 预期效果
- 用户可以方便地管理各种类型的账户
- 支持灵活的账户间转账
- 实时查看账户余额变化
- 完整的转账记录查询

## 5. 代码结构
- `pages/accounts/accounts.js`：账户管理页面逻辑
- `pages/accounts/accounts.wxml`：账户管理页面结构
- `pages/accounts/accounts.wxss`：账户管理页面样式
- 更新 `app.json` 添加新页面和 tabBar 配置

## 6. 与现有功能的关系
- 保持与现有记账和分类管理功能的独立性
- 可考虑在后续版本中将交易记录与账户关联

## 7. 实现顺序
1. 创建页面和配置
2. 实现账户数据结构和存储
3. 实现账户列表和管理功能
4. 实现转账功能
5. 测试和优化

该方案将为记账小程序添加完整的账户管理功能，支持多种账户类型和账户间转账，提升用户的财务管理体验。
